# MP3 Инструмент

Простое Android-приложение на три действия:

- **Конвертировать**: MP3 в MP3 с другим битрейтом (64–320 кбит/с).
- **Обрезать**: оставить фрагмент от времени «с» до времени «по».
- **Соединить**: склеить несколько файлов в один, порядок можно менять.

Результат сохраняется туда, куда вы укажете (системное окно сохранения).
Обработка идёт через FFmpeg (кодировщик LAME), всё происходит на телефоне.

## Как получить APK без Android Studio

1. Загрузите все файлы проекта в репозиторий GitHub (ветка `main`).
2. Откройте вкладку **Actions**, дождитесь завершения сборки «Build APK».
3. В завершённом запуске внизу, в разделе **Artifacts**, скачайте `mp3tool-debug-apk`.
4. Распакуйте архив и установите `app-debug.apk` (разрешите установку из неизвестных источников).

## Сборка в Android Studio

Откройте папку проекта, дождитесь синхронизации Gradle, нажмите Run.

## Формат времени при обрезке

`83`, `1:23` или `1:23.5` (секунды, мин:сек). Поле «по» пустое означает «до конца».
