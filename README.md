# MP3 Мастер (Android)

Простое и понятное Android-приложение для работы с MP3-файлами полностью офлайн:
1. **Качество (MP3 → MP3)** — изменение битрейта (64 / 128 / 192 / 256 / 320 кбит/с) с сохранением тегов и отображением размера «было → стало».
2. **Обрезка** — выбор отрезка ползунком + точная подстройка по ±1 секунде, встроенное прослушивание выбранного фрагмента, режим быстрой обрезки без потери качества.
3. **Соединение** — выбор нескольких MP3, сортировка порядка стрелками, надёжная склейка файлов даже с разными битрейтами и частотами.

Готовые файлы автоматически сохраняются в папку `Music/MP3Master/`.

## Как собрать APK на GitHub (без Android Studio)
1. Создайте новый репозиторий на GitHub.
2. Распакуйте архив и загрузите все файлы (включая скрытую папку `.github/workflows/build.yml`) в корень репозитория.
3. Перейдите во вкладку **Actions** в репозитории GitHub.
4. Откройте запущенный workflow **Build Android APK** (или запустите его вручную кнопкой **Run workflow**).
5. После завершения сборки (обычно 1–2 минуты) скачайте готовый файл **MP3Master-APK** в разделе **Artifacts** внизу страницы.
